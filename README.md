# FGO Codex

Base de datos de Fate/Grand Order para Android: servants, Craft Essences, banners actuales de NA y JP, misiones diarias con sus drops y un plan de mejora con los materiales que te faltan.

- Interfaz en español, inglés y japonés
- Datos del juego en inglés o japonés, con traducción al español de skills y NP
- Todo se guarda solo en tu teléfono: no hay cuentas ni inicio de sesión

## Descargar

El APK se compila automáticamente con GitHub Actions. Descarga la última versión en **[Releases](../../releases/latest)**. La app avisa sola cuando hay una versión nueva y se actualiza desde dentro.
